    Method

    Unstructured Exploration → Task Identification → Task Rehearsal

    Curiosity Based Task Discovery
    Uses RL (PPO) with a simple CNN agent to seek out novel experiences in the environment. The most unique trajectories are ones where "tasks" are potentially being implicitly executed.
    Synthetic Annotation
    The agent VLM observes the trajectories and infers the task being performed. Similar trajectories are grouped together and the model attempts to extract insight on how to properly achieve the specific task.
    Agent Rehearsal
    The agent attempts to complete the task from many starting positions, assessing its own progress and saving the successful rollouts to a separate dataset. Fine-tuning on this dataset yields a high-quality Vision Language Action model.
