Project Overview


Specific Contributions

GameBoyWorlds Framework
A Gymnasium compatible set of environments that allow agents to play 24 unique GameBoy titles, including releases from classic franchises such as Pokémon and Legend of Zelda. Titles include more obscure ROM hacks (i.e. fan made games), which are considerably less exposed to frontier Language Models during their training. With provided harnesses and documentation on how to track customized metrics, create custom tasks etc, we hope GameBoyWorlds will prove a useful resource for work on game playing embodied agents.
Task Execution Benchmark
A collection of 1200 natural language tasks with reliable success identification, allowing us to benchmark modern agents on game playing. We find that even the most powerful model XXX, YYY (placeholder).
Self Improving Agent Pipeline
A pipeline for self improving agents that use curiosity based exploration and self assessment to autonomously acquire skills. We show that agents improve their task success rates without any human demonstrations or game-specific reward engineering.

    Method

    Unstructured Exploration → Task Identification → Task Rehearsal

    Curiosity Based Task Discovery
    Uses RL (PPO) with a simple CNN agent to seek out novel experiences in the environment. The most unique trajectories are ones where "tasks" are potentially being implicitly executed.
    Synthetic Annotation
    The agent VLM observes the trajectories and infers the task being performed. Similar trajectories are grouped together and the model attempts to extract insight on how to properly achieve the specific task.
    Agent Rehearsal
    The agent attempts to complete the task from many starting positions, assessing its own progress and saving the successful rollouts to a separate dataset. Fine-tuning on this dataset yields a high-quality Vision Language Action model.

    Low-rank Finetuning of Robometer

    Robometer serves as a strong initialization for domain-specific reward fine-tuning: practitioners can adapt it to new tasks or embodiments with limited data and compute (e.g., LoRA with a single GPU) instead of training a reward model from scratch. We demonstrate this on RoboFAC; fine-tuning from Robometer substantially outperforms fine-tuning the base VLM across reward and ranking metrics.
